# ЕГЭ LAB

Бесплатная PWA-платформа для самостоятельной подготовки к ЕГЭ по русскому языку, профильной математике и информатике.

## Возможности

- Главная панель: слабые темы, журнал ошибок, ежедневная цель и серия занятий.
- Ежедневный маршрут: три задания — по одному на каждый предмет — с мгновенной проверкой и объяснением.
- Тренажёр: выбор предмета и количества вопросов, разбор ответов и история занятий.
- Карточки: интервальное повторение базовых понятий.
- Справочник: правила, формулы и алгоритмы с фильтрами по предметам.
- Прогресс: статистика ответов, тренировок и карточек.
- Профиль: регистрация и вход через Supabase, облачная синхронизация и общий рейтинг.
- Светлая и тёмная темы, адаптация под телефон, установка как PWA.

## Технологии

Обычные HTML, CSS и JavaScript без сборщика и npm. Данные сохраняются локально в браузере. При входе в аккаунт используется Supabase Auth и таблицы проекта Supabase. Публичный publishable key предназначен для клиентского приложения; безопасность данных должна обеспечиваться RLS-политиками и серверной функцией рейтинга.

## Публикация

Проект рассчитан на GitHub Pages: https://canibaa.github.io/ege-booster/

После коммита GitHub Pages автоматически публикует изменения. Если сайт установлен как PWA, при обновлении может потребоваться закрыть приложение и открыть его заново после обновления сервис-воркера.

## Важно

Материалы справочника и вопросы — учебные примеры, а не официальный комплект ФИПИ. Сверяй структуру, формулировки и критерии с официальными демоверсиями, спецификациями и кодификаторами нужного года. Не вводи в приложение чужие персональные данные.


## Расширенная подготовка к ЕГЭ-2027

- Каталог номеров: русский язык (1–27), профильная математика (1–20 по проекту 2027), информатика (1–27 по проекту 2027).
- Краткая теория, алгоритмы и типовые примеры по каждому номеру.
- Тренажёр с уровнями сложности; расширенный набор авторских задач.
- Адаптивное повторение слабых тем и персональный ежедневный план.
- Диагностический экзаменационный режим с таймером и разбором ошибок.
- Аналитика точности по предметам и темам.

**Ограничение:** встроенный экзаменационный режим использует доступный учебный банк сайта и является диагностической тренировкой, а не полным официальным вариантом КИМ. Полный открытый банк и актуальные документы доступны на [ФИПИ](https://fipi.ru/ege/otkrytyy-bank-zadaniy-ege) и в [разделе демоверсий, спецификаций и кодификаторов](https://fipi.ru/ege/demoversii-specifikacii-kodifikatory). Проекты документов ЕГЭ-2027 могут уточняться.
