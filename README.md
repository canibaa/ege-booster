# ЕГЭ-бустер

Бесплатное мобильное PWA-приложение для подготовки к ЕГЭ по информатике, математике и русскому языку.

## Возможности

- Отслеживание слабых тем и ошибок.
- Локальное сохранение данных в браузере.
- Установка на экран «Домой» на iPhone.
- Работа без интернета после первого открытия.

## Запуск

Откройте `index.html` в браузере для предварительного просмотра. Для полноценной работы PWA требуется сайт по HTTPS, например GitHub Pages.

## Публикация

В настройках репозитория откройте **Settings → Pages**, выберите публикацию из ветки `main` и папки `/ (root)`, затем нажмите **Save**.

## Технологии

Чистые HTML, CSS и JavaScript. Данные хранятся в `localStorage`; сервер и платные сервисы не требуются.
