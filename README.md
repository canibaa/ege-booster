# ЕГЭ-бустер

Бесплатное мобильное веб-приложение для подготовки к ЕГЭ. Сделано на обычных HTML, CSS и JavaScript — без npm, сборщиков и сервера.

## Что уже работает

- **Слабые темы:** список тем с процентом освоения и автоматический выбор самой слабой темы — «Босса недели».
- **Журнал ошибок:** можно записать предмет, тему, номер задания, причину и комментарий. Повторная ошибка по существующей теме снижает её показатель на 5 процентных пунктов.
- **Ежедневная цель:** счётчик занятий на сегодня и серия дней.
- **Сохранение данных:** темы, ошибки и ежедневный прогресс сохраняются в localStorage на устройстве.
- **Тёмная и светлая темы.**
- **PWA и офлайн:** сервис-воркер кэширует файлы приложения.
- **Мобильная вёрстка:** подходит для узкого экрана и учитывает безопасные области iPhone.

Вкладки «Тренинг», «Карточки» и «Прогресс» пока являются заглушками.

## Файлы

- index.html — структура экранов.
- style.css — оформление и адаптация под телефон.
- app.js — темы, ошибки, серия дней и локальное сохранение.
- manifest.json — параметры установки PWA.
- sw.js — офлайн-кэширование.
- icons/ — SVG-иконки.

## Публикация через GitHub Pages

1. Открой вкладку **Settings** этого репозитория.
2. Перейди в раздел **Pages**.
3. В **Build and deployment** выбери **Deploy from a branch**.
4. В качестве ветки выбери main, папку — / (root), затем нажми **Save**.
5. Дождись завершения публикации. Адрес сайта будет: https://canibaa.github.io/ege-booster/

Все пути к стилям, скриптам, манифесту и сервис-воркеру относительные, поэтому приложение рассчитано на публикацию в подпапке /ege-booster/.

## Установка на iPhone

После публикации открой сайт в Safari → нажми «Поделиться» → «На экран Домой». Для работы офлайн сначала открой приложение с интернетом, чтобы файлы закэшировались.

## Важно

Данные хранятся только в браузере текущего устройства. Они не синхронизируются между устройствами и могут исчезнуть при очистке данных сайта. Не вводи в приложение пароли и другую конфиденциальную информацию.
